Privacy policy

Updated 14 October 2026 · YourSafe

This policy explains how the YourSafe Windows app, browser extension, and website handle data. You do not need an online account to use the password vault.

Data we handle

The app stores the details you add to the vault: account titles, usernames, passwords, website addresses, notes, TOTP settings, and recovery codes. The vault is encrypted and saved locally on your Windows PC.

When you open the extension, it uses the selected page’s address to find matching accounts in the desktop vault. It receives account titles, usernames, and whether each account has a password or TOTP. When you request autofill or a code and approve the request on the desktop, the data needed for that action is handled on the same PC.

The selected tab’s URL and origin are used temporarily to match accounts and check the destination. The origin is sent to the desktop app on the same PC. The extension does not keep a browsing history. After you click Fill, its script checks login fields, forms, visibility, and form destinations to decide where it can fill safely. Passwords are filled only after desktop approval. The extension does not collect the full page’s contents.

How data is used and shared

Vault data and selected-page data are used only for the actions you request: managing the vault, finding accounts, filling login details, and viewing or copying codes. The extension communicates with the desktop app through local Native Messaging. This data is not sent to the developer’s servers.

Autofill puts the username and password into the selected website’s form. That website can read the filled values under its own policies. YourSafe does not submit the login form.

The Windows app and extension do not sell vault data, use it for advertising, send telemetry, or build browsing profiles. The developer cannot access your vault and does not keep a copy for recovery.

The extension’s use of data follows the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only for the stated features, never for advertising. Vault data is not transferred to the developer or advertisers.

Browser extension permissions

  • nativeMessaging: connects to YourSafe Desktop on the same PC to get data for the action you request.
  • activeTab: temporarily accesses the selected tab when you open the extension.
  • scripting: finds and fills login fields on the selected page when you request autofill.
  • webNavigation: checks the destination and cancels the action if the page changes, to avoid filling the wrong page.

Storage and your choices

The extension does not store your passwords or vault, or sync the vault to the cloud. It holds data temporarily in memory for the requested action. Passwords are not saved in the extension’s session state. TOTP results may remain briefly until the code or session expires, or the action is cancelled.

You can edit or delete accounts in the desktop app, turn off browser integration, or uninstall the extension. Uninstalling the desktop app does not delete the vault. Exported backups stay where you save them. You control how long to keep the vault and backups, and when to delete them. Copied data passes through the Windows clipboard and may be affected by clipboard history or sync settings.

Website and feedback

The website uses Google Analytics 4 to count visits and link clicks. It may use cookies and process browser and device information as described in how Google uses data.

The Windows app, extension, and demo login page do not use Google Analytics. The demo processes the form in your browser without sending or saving what you enter. The website is hosted on GitHub Pages, which may process connection information under GitHub’s privacy policy.

If you email the developer or open an issue, the information you provide is used to respond to your question or feedback. Public GitHub issues can be read by others. Do not send passwords, verification codes, recovery keys, or vault files. You can ask the developer to delete any support information they retain. Data on third-party services is covered by those services’ policies.
